# State EV Rebate Example: Colorado (Illustrative)

*This is a simplified, illustrative example of how a state-level EV rebate
program can work, using Colorado's general approach as a reference point for
teaching purposes. Program names, funding availability, and eligibility rules
change frequently — verify current details with the state's official program
before relying on this for a purchase decision.*

Colorado has historically offered a state tax credit for EV purchases and
leases, structured differently from a point-of-sale rebate — buyers typically
claim it when filing state income taxes rather than receiving a discount at the
dealership, though some dealerships have offered to apply an equivalent
discount directly at the point of sale in exchange for the buyer assigning the
credit to them.

Key features commonly associated with programs like this include:

- Separate credit amounts for purchased versus leased vehicles, with leases
  often qualifying for a smaller amount.
- A vehicle price cap above which the credit is reduced or unavailable.
- Additional incentives for buyers trading in an older gas-powered vehicle
  through associated "clean vehicle exchange" programs.

As with any state program, exact dollar amounts and eligibility rules are set
by state legislation and can change from year to year, so a buyer should
confirm current details directly with the state's official resources.
